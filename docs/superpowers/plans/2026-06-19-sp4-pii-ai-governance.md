## Task 1：PiiMasker + 單元測試

**Files:** `service/PiiMasker.java`、`test/.../service/PiiMaskerTest.java`

- [ ] **Step 1:** 建 `backend/src/main/java/com/aicrm/crm/service/PiiMasker.java`：
```java
package com.aicrm.crm.service;

import java.util.regex.Pattern;

/**
 * PII 遮罩工具：送 LLM 前遮蔽 email / 電話 / 統編，降低個資外洩風險。
 */
public final class PiiMasker {

    private static final Pattern EMAIL = Pattern.compile("[\\w.+-]+@[\\w.-]+\\.[A-Za-z]{2,}");
    private static final Pattern PHONE = Pattern.compile("09\\d{2}[-\\s]?\\d{3}[-\\s]?\\d{3}|0\\d{1,2}-?\\d{6,8}");
    private static final Pattern TAX_ID = Pattern.compile("(?<!\\d)\\d{8}(?!\\d)");

    private PiiMasker() {
    }

    /**
     * 遮罩單一字串中的 email / 電話 / 統編。
     *
     * @param text 原始字串（可為 null）
     * @return 遮罩後字串
     */
    public static String mask(String text) {
        if (text == null || text.isBlank()) return text;
        String r = EMAIL.matcher(text).replaceAll("[已遮罩EMAIL]");
        r = PHONE.matcher(r).replaceAll("[已遮罩電話]");
        r = TAX_ID.matcher(r).replaceAll("[已遮罩統編]");
        return r;
    }
}
```

- [ ] **Step 2:** 建 `PiiMaskerTest`：驗 email/phone/taxId 被遮罩、一般中文業務文字不變、null/空字串安全回傳。至少 4 測試。

- [ ] **Step 3:** Run `mvn -pl backend -Dtest=PiiMaskerTest test` → 全綠。

- [ ] **Step 1:** V6 migration（Postgres，Testcontainers 與 prod 皆適用）：
```sql
create table ai_call_log (
    id bigint generated by default as identity primary key,
    customer_id bigint,
    call_type varchar(40) not null,
    model varchar(120),
    prompt_tokens int not null default 0,
    completion_tokens int not null default 0,
    total_tokens int not null default 0,
    ai_enabled boolean not null,
    pii_masked boolean not null,
    answer text,
    created_at timestamp with time zone not null
);
create index idx_ai_call_log_customer on ai_call_log(customer_id);
create index idx_ai_call_log_created on ai_call_log(created_at);

create table ai_feedback (
    id bigint generated by default as identity primary key,
    call_log_id bigint not null references ai_call_log(id),
    decision varchar(20) not null,
    note varchar(1000),
    created_at timestamp with time zone not null,
    created_by varchar(120) not null
);
create index idx_ai_feedback_call on ai_feedback(call_log_id);
```

## Task 4：端點 + 權限

**Files:** 修改 `api/AiController.java`、`security/SecurityConfig.java`

- [ ] **Step 1:** AiController 注入 `AiGovernanceService`，加：
```java
    @PostMapping("/calls/{id}/feedback")
    public void feedback(@PathVariable Long id, @Valid @RequestBody Dtos.AiFeedbackRequest request,
                         java.security.Principal principal) {
        aiGovernanceService.feedback(id,
            com.aicrm.crm.domain.FeedbackDecision.valueOf(request.decision()),
            request.note(),
            principal != null ? principal.getName() : "unknown");
    }

    @GetMapping("/usage")
    public Dtos.UsageSummaryResponse usage() {
        return aiGovernanceService.usage();
    }
```
> Principal 來源：JwtAuthenticationFilter 設的 authentication principal 是 `JwtService.AuthPrincipal`（含 username()）。若 `principal.getName()` 不適用，改注入 `Authentication` 取 principal。讀 JwtAuthenticationFilter 確認。
